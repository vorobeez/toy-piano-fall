# Toy piano fall

An interactive Three.js demo where toy pianos fall into the scene, collide with the floor and each other, and produce playful synthesized sounds. You can click or tap piano keys to play notes while the physics simulation keeps adding new pianos over time.

This project was created to solidify material from the first three chapters of the [Three.js Journey](https://threejs-journey.com/) course: Basics, Classic techniques, and Advanced techniques.

[Live demo](https://toy-piano-fall.vercel.app/)

## Features

- 3D toy piano model created in Blender and rendered with Three.js
- Physics simulation powered by Rapier
- Procedural audio and note playback with Tone.js
- Interactive piano keys via pointer raycasting

## Tech Stack

- TypeScript
- Vite
- Three.js
- Rapier 3D
- Tone.js

## Running Locally

```bash
npm install
npm run dev
```
